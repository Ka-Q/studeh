# Studeh

A local study app for learning by obstructing and revealing parts of images.

## Requirements

- Node.js >= 24

## Running locally

### 1. Install

Paste this into a terminal:

```sh
git clone https://github.com/Ka-Q/studeh.git && cd studeh && npm install
```

### 2. Run

```sh
npm start
```

This builds the project and starts the server, opening the UI in your browser automatically. By default it runs on `http://localhost:3000` (override with the `PORT` environment variable).

Next time, just run `npm start` again from inside the `studeh` folder.

### Development mode

For active development, run:

```sh
npm run dev
```

This watches and rebuilds the client, static assets, and server on change, restarting the server as needed.
